# Sundrop 🌻

## ☀️ Overview
Sundrop is a tiny summer-themed arcade game created for A Lil Summer GameJam hosted by SlombyDev on itch.io! Guide a sunflower across a sunny field, collect falling sunshine, and avoid clouds before summer comes to an end🌻

## 🎮 How to Play
- move the sunflower left and right using **Arrow Keys** or **A / D**
- catch ☀️ sunshine to increase your score
- avoid ☁️ clouds to protect your score
- you have **60 seconds** to collect as much sunshine as possible
- when the timer reaches zero, see your final score and play again!

## 🛠️ Tech Stack

## ✨ Features
- simple yet fun gameplay: move sunflower from left to right using the keyboard
- timer and score tracking
- hovering effects
- pixel / retro inspired interface
- sunflower themed
